# Keyboard and workspace reference

Default Windows shortcuts, canvas input gestures, and workspace customization options.

## Default shortcuts

These are the default Windows shortcuts. Editor actions apply when you're working on the canvas; text and number fields keep their normal editing keys.

| Action | Shortcut |
| --- | --- |
| New document | `Ctrl+N` |
| Open an image | `Ctrl+O` |
| Save | `Ctrl+S` |
| Save as | `Ctrl+Shift+S` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` or `Ctrl+Shift+Z` |
| Search commands | `Ctrl+P` or `Ctrl+Shift+P` |
| Open Settings | `Ctrl+,` |
| Copy / cut / paste | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Duplicate | `Ctrl+D` |
| Open the tool wheel | `Tab` over the canvas |
| Center the canvas view | `Home` |
| Toggle the pixel grid | `Ctrl+G` |

Copy, cut, paste, and duplicate follow what you're editing: selected animation frames, a pixel selection, or selected layers. Click the area you want to work with first.

## Move around the canvas

Zoom with the mouse wheel. Hold `Space` and move the pointer to pan, or drag with the middle mouse button. Touchpad scrolling pans and pinching zooms when configured for a touchpad.

With **Select** active, hold `T`, `R`, or `S` while dragging to move, rotate, or scale the active layer. The tool also supports clicking to start a transform you can confirm or cancel. Follow the canvas hints for the current interaction.

In the Layers panel, `Ctrl`-click toggles a layer in the selection and `Shift`-click selects a range. `Alt`-click a visibility eye to isolate a layer and restore the previous view when you're done.

## Command search

Press `Ctrl+P`, type what you want to do, and choose a matching command. Try “crop,” “mirror,” or “guide.” Some commands become available only when a document or suitable layer is active.

## Keybinding configuration

Open **Keybindings** from Settings. Search for an action, record a replacement shortcut, or add an alternative. You can reset bindings and import or export a keybinding profile.

Custom binding support covers registered executable commands and selected application actions. Some local gestures, held tool keys, and mouse interactions are available for reference only. Paintbro doesn't currently let you remap every interaction.

## Workspace configuration

Move and resize dock panels to arrange the workspace. Use **Personalization → Manage layouts** to save and apply layouts, toolbar arrangements, and tool-wheel setups. You can choose which available parts of a preset to apply.

Settings also has a **Customize toolbar** shortcut. Reorder groups, choose their primary tools, or move tools between groups to suit how you work.
